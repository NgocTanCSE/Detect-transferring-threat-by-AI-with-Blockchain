# Plan: Fix HF Deployment - Frontend Node.js Missing

## Problem
Backend runs successfully (returns 200 OK), but frontend crashes because Node.js is not installed in the runtime Docker image (`python:3.11-slim`).

Error: `/app/entrypoint.sh: line 55: /usr/bin/node: No such file or directory`

## Root Cause
Dockerfile Stage 2 uses `python:3.11-slim` which does NOT include Node.js. Node.js is only available in Stage 1 (`node:18-alpine`) for building the frontend, but the binary is never copied to the runtime stage.

## Fix

### File: `Dockerfile`
Add Node.js installation in Stage 2 (runtime):

```dockerfile
# --- Stage 2: Backend & Runtime ---
FROM python:3.11-slim AS runtime

# Install Node.js + system deps
RUN apt-get update && apt-get install --no-install-recommends -y \
  gcc libpq-dev curl \
  && curl -fsSL https://deb.nodesource.com/setup_18.x | bash - \
  && apt-get install -y nodejs \
  && rm -rf /var/lib/apt/lists/*
```

### File: `entrypoint.sh`
Fix node path - use `node` instead of `/usr/bin/node` since it will now be in PATH after installation:

```bash
HOSTNAME=0.0.0.0 PORT=7860 BACKEND_URL=http://127.0.0.1:8000 NODE_ENV=production node server.js 2>&1 &
```
