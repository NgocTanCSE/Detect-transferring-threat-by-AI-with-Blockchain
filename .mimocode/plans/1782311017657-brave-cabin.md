## Issue 2: Scanner POST /alerts returns 404
**Root cause**: Scanner calls `POST /alerts` on backend, but backend has no such route (only GET /alerts/recent).

**Fix**: In `scanner.py`, insert alert directly into database instead of calling HTTP endpoint.

### File: `backend/scanner.py` (line 164-181)
Replace HTTP POST with direct DB insert:
```python
# Instead of: requests.post(f"{ALERT_SERVICE_URL}/alerts", ...)
# Do: Insert alert directly into database
from app.models.models import Alert as AlertModel
alert = AlertModel(
    wallet_address=wallet_address,
    alert_type="HIGH_RISK_DETECTION",
    severity=risk_level,
    message=f"Scanner detected high-risk activity ({risk_score}%)",
    risk_score=float(risk_score),
    chain_id="ethereum",
)
session.add(alert)
session.commit()
```
