## 2. LIÊN KẾT GIỮA CÁC TẦNG

### 2.1 DB → BE
- SQLAlchemy ORM models kết nối trực tiếp với PostgreSQL
- `get_db()` dependency injection trong FastAPI
- `ensure_schema()` auto-migration khi startup
- Multi-tenant scoping qua `organization_id`

### 2.2 BE → API
- FastAPI routers mounted trong `main.py`
- Auth middleware (JWT, CSRF, rate limiting)
- CORS configuration
- Security headers middleware

### 2.3 API → FE
- Next.js API route proxy (`/api/[...path]/route.ts`)
- Next.js rewrites (`next.config.mjs`)
- `authFetch()` function automatically adds JWT token
- React Query for data fetching

### 2.4 Microservices → API Gateway
- API Gateway (port 8001) reverse proxies to all services
- JWT/API-key validation at gateway level
- Circuit breaker for fault tolerance

## 3. LUỒNG CỦA DỰ ÁN

### 3.1 Luồng chính:
1. User login → JWT token
2. Frontend requests → API route proxy → API Gateway
3. API Gateway → routes to appropriate microservice OR Python AI service
4. Microservice reads/writes to PostgreSQL
5. AI service runs detection, returns results
6. Results flow back to Frontend

### 3.2 Luồng AI Analysis:
1. User submits wallet address
2. Frontend calls `/analyze/{address}`
3. Backend runs MultiAgentDetectionEngine
4. MLRiskPredictor loads pkl model
5. Gemini API generates natural language insight
6. Results returned to Frontend

### 3.3 Luồng Background Scanner:
1. scanner.py polls wallets periodically
2. Runs AI detection engine
3. Generates alerts in database
4. Alert service sends notifications via RabbitMQ
